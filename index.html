CCNA — Solar Plex Arnhem

2026 ◆ Cisco IOS VLAN OSPF ACL

Topologie

Projectcontext

Solar Plex is een duurzame energiebedrijf met vestigingen in Nijmegen (hoofdkantoor), Doetinchem en Arnhem. De netwerken in Nijmegen en Doetinchem zijn bestaande omgevingen. In Arnhem is een nieuwe werkplaats ingericht en het netwerk was nog niet afgerond. De opdracht is om dit netwerk volledig te configureren en op te zetten in Cisco Packet Tracer.

Het Arnhemse netwerk bedient twee VLANs voor productie- en marketingafdelingen, plus een apart gast-WiFi VLAN met ACL-beveiliging zodat gasten niet bij het intranet kunnen.

B. Maak de VLAN's aan op de Core01_ARN met de juiste namen

Op de Core01_ARN (de Layer 3 switch) worden alle VLANs aangemaakt met de juiste namen. Dit is de VTP Server, dus de VLANs worden automatisch gesynchroniseerd naar de client-switches.

Core01_ARN# configure terminal

Core01_ARN(config-vlan)# exit

De VLANs 5, 10 en 20 komen overeen met de afdelingen op het hoofdkantoor in Nijmegen en worden meegesynchroniseerd via VTP. VLAN 30, 40 en 50 zijn specifiek voor Arnhem.

C. Configureer VTP

VTP (VLAN Trunking Protocol) zorgt ervoor dat VLAN-informatie automatisch wordt verspreid via trunk-links naar de client-switches, zodat je VLANs maar op één plek hoeft te beheren.

Core01_ARN — VTP Server

Core01_ARN(config)# vtp domain SOLAR
Core01_ARN(config)# vtp mode server

SW01-ARN & SW02-ARN — VTP Client

SW01-ARN(config)# vtp domain SOLAR
SW01-ARN(config)# vtp mode client

SW02-ARN(config)# vtp domain SOLAR
SW02-ARN(config)# vtp mode client

Zodra de trunk-verbindingen actief zijn, ontvangen de client-switches automatisch de VLAN-database van de server. Dit is te verifiëren met show vtp status en show vlan brief.

D. Onderzoek welke switch de root is

Spanning Tree Protocol (STP) voorkomt netwerklussen in geswitchte netwerken. Standaard wordt de root bridge bepaald op basis van het laagste bridge-ID (prioriteit + MAC-adres).

Core01_ARN# show spanning-tree

Kijk bij elk VLAN naar de regel "This bridge is the root". Als dit niet zo is, pas je de prioriteit aan.

E. Maak Core01_ARN de root switch voor alle VLAN's.

Om zeker te zijn dat Core01_ARN de root is voor alle VLANs, stellen we dit expliciet in:

Core01_ARN(config)# spanning-tree vlan 1,5,10,20,30,40,50 root primary

Dit commando verlaagt de prioriteit automatisch naar 24576 (of lager dan de huidige laagste) zodat Core01_ARN altijd wint.

Configureer de Gast Wifi en ACL

A. Plaats de Access Point en Laptop in de juiste VLan

B. Configureer de AP_Gast

AP_Gast is direct aangesloten op poort Fa0/24 van Core01_ARN in VLAN 50. Configureer de access-poort op de switch en stel de WiFi-instellingen in op het access point:

C. Configureer een ACL op de Core01_ARN met de volgende commando:

access-list 150 deny ip 10.10.50.0 0.0.0.255 10.10.30.0 0.0.0.255
access-list 150 deny ip 10.10.50.0 0.0.0.255 10.10.40.0 0.0.0.255
access-list 150 deny ip 10.10.50.0 0.0.0.255 172.16.10.0 0.0.0.255
access-list 150 deny ip 10.10.50.0 0.0.0.255 172.16.5.0 0.0.0.255
access-list 150 deny ip 10.10.50.0 0.0.0.255 172.16.20.0 0.0.0.255
access-list 150 permit ip any any

interface Vlan50
  ip access-group 150 in

De ACL (Access Control List) wordt gebruikt om gast-verkeer te beperken. Gasten mogen alleen naar internet en naar www.solar.com, maar niet naar interne netwerken van andere VLANs. De ACL wordt inbound toegepast op de VLAN 50-interface, zodat verkeer wordt gefilterd op het moment dat het de switch inkomt vanuit het gastnetwerk.

De laatste regel permit ip any any is cruciaal: zonder deze regel zou de impliciete deny all aan het einde van elke ACL ook het internetverkeer blokkeren. Nu wordt alleen het intranet-verkeer geblokkeerd, en al het overige (inclusief internet) doorgelaten.

Opdracht 3 — Testen

Plaats screenshots van alle stappen en geef aan hoe je dit hebt gedaan en waarom het wel of niet is gelukt.

A. Ga via PC3 naar www.solar.com

PC3 zit in VLAN 40 (Marketing) en krijgt via DHCP een IP in 10.10.40.0/24. Open de webbrowser op PC3 en navigeer naar www.solar.com. De DNS-server (62.36.55.85) lost de domeinnaam op en de webserver reageert. Dit werkt als de DHCP-pool correct is geconfigureerd en OSPF-routing actief is.

B. Ga via de webbrowser van PC5 naar 172.16.5.30

PC5 zit in VLAN 30 (Productie). Het adres 172.16.5.30 is een server op het intranet van Nijmegen (IT-subnet). Via de browser op PC5 navigeer je naar dit adres. Dit vereist dat OSPF de route naar 172.16.5.0/24 heeft geleerd via de router in Nijmegen. Als OSPF correct convergeert, is de server bereikbaar.

C. Ping vanuit PC2 naar PC4

PC2 bevindt zich buiten Arnhem (op een ander subnet). PC4 zit in VLAN 30 op 10.10.30.0/24. Open de command prompt op PC2 en voer uit:

ping 10.10.30.x

Een succesvolle ping bevestigt dat inter-site routing via OSPF functioneert en dat de SVI van VLAN 30 actief is. Als de ping mislukt, controleer dan eerst met show ip route op Core01_ARN of de routes aanwezig zijn.

D. Verifieer als je via het gasten WiFi op de INTRANET kunt, dit zou niet mogen

Laptop_gast verbindt met het Solar_gast netwerk en ontvangt een IP in 10.10.50.0/24. Test het volgende:

Moet mislukken (geblokkeerd door ACL 150):

ping 10.10.30.1   ← VLAN 30 Productie
ping 10.10.40.1   ← VLAN 40 Marketing
ping 172.16.5.1   ← IT Nijmegen

Je mag alleen op www.solar.com via het gasten WiFi:

Webbrowser → www.solar.com

De ACL laat permit ip any any toe voor al het andere verkeer, waardoor internetverkeer doorkomt. De specifieke deny-regels blokkeren uitsluitend de interne subnetten. Dit is de juiste werking: gasten hebben internettoegang maar kunnen het bedrijfsnetwerk niet benaderen.

Casus sportvereniging

De plaatselijke sportvereniging heeft een nieuw pakket voor het bijhouden van de administratie in gebruik genomen. Met dit pakket kunnen (nog) geen berichten worden verzonden naar leden die achterlopen met het betalen van de contributie. Er kan wel een export van alle leden naar een csv-bestand worden gemaakt. Deze export (leden.csv) bevat het lidmaatschapsnummer en het volledige adres van de leden.

Er kan ook een export worden gemaakt van het per de eerste van de volgende maand te betalen bedrag (contributie.csv). Deze export bevat het lidmaatschapsnummer en het openstaande bedrag van de leden. Volledige functie om CSV-data uit te lezen

Deze functie kun je voor bijna elk csv-bestand gebruiken. De functie haalt de header uit de eerste regel en zet alle overige rijen in een aparte datalijst.

import csv

def lees_csv_bestand(bestandsnaam):
    # Open het csv-bestand.
    with open(bestandsnaam, newline="", encoding="utf-8") as bestand:
        # Lees elke regel als een lijst.
        reader = csv.reader(bestand)

        # Pak de eerste regel als header.
        header = next(reader)

        # De rest van het bestand is de data.
        data = list(reader)

    # Geef beide lijsten terug.
    return header, data

Header uitlezen met next()

Je kunt de header ook direct uitlezen met next(reader). Dat is vaak overzichtelijker: next(reader) pakt de eerste regel uit het csv-bestand en daarna blijven alleen de datarijen over.

import csv

def lees_csv_bestand(bestandsnaam):

        reader = csv.reader(bestand)

Kort gezegd: header = next(reader) betekent: lees de eerste rij en bewaar die als header. Daarna begint reader automatisch bij de tweede rij.

Deze volledige code leest beide csv-bestanden uit, valideert de autodata, koppelt de bestanden via kenteken en toont alles samen in een overzichtelijke tabel.

import csv
import re

def lees_csv_bestand(bestandsnaam):
    # Open het csv-bestand.
    with open(bestandsnaam, newline="", encoding="utf-8") as bestand:
        reader = csv.reader(bestand)

        # De eerste rij is de header.
        header = next(reader)

        # Alle rijen daarna zijn de data.
        data = list(reader)

    return header, data

def kolom_index(header, kolomnaam):
    # Zoek op welke plek een kolom staat.
    return header.index(kolomnaam)

def bedrag_naar_float(waarde):
    # Maak van tekst een getal.
    return float(waarde.replace(",", "."))

def valideer_kenteken(kenteken):
    # Voorbeeldformaat: AB-123-C
    kenteken = kenteken.strip().upper()
    patroon = r"[A-Z]{2}-[0-9]{3}-[A-Z]"

    return re.fullmatch(patroon, kenteken) is not None

def valideer_postcode(postcode):
    # Voorbeeldformaat: 1234 AB of 1234AB
    postcode = postcode.strip().upper()
    patroon = r"[1-9][0-9]{3} ?[A-Z]{2}"

    return re.fullmatch(patroon, postcode) is not None

def valideer_plaats(plaats):
    # Een plaats mag niet leeg zijn en moet vooral uit letters bestaan.
    plaats = plaats.strip()
    controle = plaats.replace(" ", "").replace("-", "").replace("'", "")

    return len(plaats) >= 2 and controle.isalpha()

def valideer_auto_rij(autos_header, auto):
    kenteken_index = kolom_index(autos_header, "kenteken")
    postcode_index = kolom_index(autos_header, "postcode")
    plaats_index = kolom_index(autos_header, "plaats")

    kenteken = auto[kenteken_index]
    postcode = auto[postcode_index]
    plaats = auto[plaats_index]

    if not valideer_kenteken(kenteken):
        return False, "Ongeldig kenteken"

    if not valideer_postcode(postcode):
        return False, "Ongeldige postcode"

    if not valideer_plaats(plaats):
        return False, "Ongeldige plaats"

    return True, "Rij is geldig"

def koppel_autos_met_kosten(autos_header, autos_data, kosten_header, kosten_data):
    # Zoek de juiste kolomposities in autos.csv.
    auto_kenteken_index = kolom_index(autos_header, "kenteken")
    merk_index = kolom_index(autos_header, "merk")
    kleur_index = kolom_index(autos_header, "kleur")
    type_index = kolom_index(autos_header, "type")
    postcode_index = kolom_index(autos_header, "postcode")
    plaats_index = kolom_index(autos_header, "plaats")

    # Zoek de juiste kolomposities in kosten.csv.
    kosten_kenteken_index = kolom_index(kosten_header, "kenteken")
    bedrag_index = kolom_index(kosten_header, "bedrag")

    # Maak een snelle zoeklijst met kenteken als sleutel.
    autos_op_kenteken = {}
    fouten = []

    for auto in autos_data:
        is_geldig, melding = valideer_auto_rij(autos_header, auto)

        if not is_geldig:
            fouten.append([auto, melding])
            continue

        kenteken = auto[auto_kenteken_index].strip().upper()
        autos_op_kenteken[kenteken] = auto

    # Dit wordt de header van het eindresultaat.
    resultaat_header = ["kenteken", "merk", "kleur", "type", "postcode", "plaats", "bedrag"]

    # Hier komen alle gekoppelde rijen in.
    resultaat_data = []

    for kostenrij in kosten_data:
        kenteken = kostenrij[kosten_kenteken_index].strip().upper()
        bedrag = bedrag_naar_float(kostenrij[bedrag_index])

        if kenteken in autos_op_kenteken:
            auto = autos_op_kenteken[kenteken]

            resultaat_data.append([
                kenteken,
                auto[merk_index],
                auto[kleur_index],
                auto[type_index],
                auto[postcode_index],
                auto[plaats_index],
                f"{bedrag:.2f}"
            ])

    return resultaat_header, resultaat_data, fouten

def toon_tabel(header, data):
    # Toon de header netjes bovenaan.
    print(
        f"{header[0]:<10} {header[1]:<15} {header[2]:<10} "
        f"{header[3]:<12} {header[4]:<10} {header[5]:<12} {header[6]:>10}"
    )
    print("-" * 88)

    # Toon daarna elke rij data.
    for rij in data:
        print(
            f"{rij[0]:<10} {rij[1]:<15} {rij[2]:<10} "
            f"{rij[3]:<12} {rij[4]:<10} {rij[5]:<12} {rij[6]:>10}"
        )

# Lees de twee csv-bestanden in.
autos_header, autos_data = lees_csv_bestand("autos.csv")
kosten_header, kosten_data = lees_csv_bestand("kosten.csv")

# Stuur de ingelezen data naar de koppelfunctie.
overzicht_header, overzicht_data, fouten = koppel_autos_met_kosten(
    autos_header,
    autos_data,
    kosten_header,
    kosten_data
)

# Toon alles bij elkaar.
toon_tabel(overzicht_header, overzicht_data)

# Toon eventuele fouten.
for fout in fouten:
    print(fout)

4. Data valideren: kenteken, postcode en plaats

Valideren betekent dat je controleert of data klopt voordat je ermee verder werkt. Zo voorkom je dat verkeerde kentekens, postcodes of plaatsnamen in je overzicht komen.

Voorbeeld van losse controles:

print(valideer_kenteken("AB-123-C"))   # True
print(valideer_kenteken("123-ABC"))    # False

print(valideer_postcode("0123 AB"))    # False

print(valideer_plaats("Arnhem"))       # True

Als je csv-bestand bijvoorbeeld ook postcode en plaats heeft, kun je een volledige rij controleren voordat je die gebruikt.

def valideer_auto_rij(header, rij):

    postcode_index = header.index("postcode")
    plaats_index = header.index("plaats")

    kenteken = rij[kenteken_index]
    postcode = rij[postcode_index]
    plaats = rij[plaats_index]

    if not valideer_kenteken(kenteken):
        return False, "Ongeldig kenteken"

    if not valideer_postcode(postcode):
        return False, "Ongeldige postcode"

    if not valideer_plaats(plaats):
        return False, "Ongeldige plaats"

    return True, "Rij is geldig"

In de functie zelf komen deze waarden binnen als parameters:

def toon_tabel(header, data):
