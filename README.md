# Examens

Dit project bevat een eenvoudige webpagina voor examens, met scripts, stylesheets en statische bestanden.

## Inhoud van de pagina

De pagina is opgebouwd als een kennisarchief voor technische examens en bevat:

- Een startpagina met uitleg, studietips en een overzicht van onderwerpen.
- Een zijbalk met tabbladen voor `CCNA`, `Python` en `Security`.
- Een dynamische inhoudsopgave (TOC) per onderwerp.
- Een uitgebreide CCNA-sectie met:
  - netwerktopologie (met afbeelding),
  - projectcontext,
  - stapsgewijze opdrachten,
  - configuratievoorbeelden voor VLAN, VTP, STP, SVI en DHCP.
- Onderwerpkaarten voor Python en Security (gemarkeerd als binnenkort beschikbaar).
